# Daily AI News

面向 AI / Agent / AI Infra 的每日技术简报。

## 内容结构

每天的简报尽量覆盖：

1. **AI 行业大事（全球）**：基础模型、AGI、AI 产品、重要论文、产业变化
2. **国内 AI 动态**：国内模型公司、大厂、创业公司、政策与行业变化
3. **AI for AI / AI4Science**：AI 辅助研发、自动化科研、科学智能
4. **Agent / Coding Agent / Computer Use**：Agent、Coding Agent、Computer Use、工具调用与协议生态
5. **Agentic RL / RL Infra**：Agentic RL、多轮训练、环境、Rollout、奖励、数据闭环
6. **Agent Sandbox / Runtime / Infra**：Sandbox、Kubernetes、Firecracker、Kata、容器与虚拟化、Env-as-a-Service
7. **训练框架与基础设施更新**：verl、AReaL、Roll、vLLM、SGLang、Ray 等值得关注的更新
8. **值得读的论文 / Repo / 技术文章**
9. **职业与技术方向观察**：对 AI Infra / Agent Infra / 云原生工程师有实际价值的趋势判断

## 归档

每日内容位于 [`daily/`](./daily/) 目录，文件名格式：

```text
daily/YYYY-MM-DD.md
```
