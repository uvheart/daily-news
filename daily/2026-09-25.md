## 今日概览

### 【一句话判断】
今天的主线是 **Agent Infra 从无状态模型服务进入 Stateful Runtime**。共享 KV、持续多模态会话、后台工具执行与 persistent state 同时升温；下一阶段更值得投入的是 **Context/State Data Plane、Agent Runtime、Environment-as-a-Service，以及训练/采样/推理状态一致性**。

### 【今日 Top 5】

1. **Nebius + WEKA：Agentic Coding 下共享 KV Cache 请求吞吐 2.4×**
   - **2026-09-24。** 512 个活跃 Agent session、DeepSeek-V4-Pro、vLLM v0.23 的 8 小时测试中，共享 KV 命中率 40%→93%，p50 TTFT 5.68s→1.05s，输出 token/GPU-hour 约 3.7×。
   - **为什么重要：** KV 正从单机优化变成独立 **Context Data Plane**。
   - 来源：[Nebius](https://nebius.com/blog/posts/nebius-weka-shared-kv-cache-benchmark-hgx-b300)

2. **Gemini 3.8 Live：持续对话期间支持后台异步工具执行**
   - **2026-09-24。** Google 将实时视频、speech-to-speech、视觉输入与 asynchronous tool execution 放进同一会话。
   - **为什么重要：** Realtime Agent 更像 event loop / actor，而不是同步 workflow DAG。
   - 来源：[Google](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-with-live-avatar/)

3. **Google Research：multi-agent + persistent visual memory 做长视频生成**
   - **2026-09-24。** CANVAS 显式维护角色/地点/对象状态，A²RD 用多模态 memory 做闭环 refinement。
   - **为什么重要：** 长任务开始依赖显式 world state。
   - 来源：[Google Research](https://research.google/blog/coherent-long-form-video-generation/)

4. **NVIDIA、Google DeepMind、EMBL-EBI 开放 2,800+ 病毒蛋白复合物结构**
   - **2026-09-24。** AlphaFold2 + BioNeMo 批量生成并进入 AlphaFold Database。
   - **为什么重要：** AI4Science 正形成“批量推理→科学资产→数据平台→验证”的工程闭环。
   - 来源：[NVIDIA](https://blogs.nvidia.com/blog/open-protein-dataset/)

5. **Kimi K3 进入 Snowflake Cortex AI private preview**
   - **2026-09-24。** Snowflake 提醒 K3 对 conversation history 很敏感，中途切模型或 harness 丢失 reasoning history 可能影响效果。
   - **为什么重要：** Model API 兼容不等于 Agent Runtime 兼容。
   - 来源：[Snowflake](https://www.snowflake.com/en/blog/kimi-k3-cortex-ai/)

2. **Agent Runtime 进入 actor/event-loop 语义**：持续 session、background task、checkpoint/resume、late result 会成为基本能力。
3. **Agent Runtime 与 RL Infra 共用 Environment/Trajectory 基础设施**：线上 trace、rollout、verifier、replay 的数据结构正在靠拢。
